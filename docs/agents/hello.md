# hello

- Version: 0.1.0 · Mode: hitl
- Repositories: OWASP/CheatSheetSeries
- Class: `workers/agents/src/agents/hello.ts` · Policy: `workers/github-broker/policy/policy.json#agents.hello`

## Purpose

Smoke-test agent. Proves the whole pipeline end to end: routing, state, kill switch, broker
denial and approval paths, attestation and CLI verification. It does not call a model.

## Inputs (all untrusted)

None in the scaffold. The `/run` request comes from the Access-authenticated admin path.

## Actions requested

`issue.comment` on the configured repo, only when the example line in `run()` is enabled and a
human approves.

## PAT scopes

Issues: read & write on OWASP/CheatSheetSeries only. Expiry ≤ 90 days. Stored as the GitHub
Environment secret `PAT_HELLO`; CI syncs it into Secrets Store.

## Keys

Generated by the broker Keyring on first use; `custodes keys list` shows the active key id.

## Schedule / triggers

Manual: `custodes agents run hello`.

## Failure modes

Halted → `run()` returns `ok: false` and records the reason in state. Broker unavailable → `act()`
throws; nothing is posted.

## How to halt

`custodes agents halt hello --reason "..."`
